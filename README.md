# Docx 智能解析与还原系统

这是一个功能强大的 Docx 文档处理系统，能够解析文档中的样式、表格（含合并单元格）以及图片，并能将其高保真地还原。

## 目录结构
- `docx解析器/`: 包含解析核心逻辑，负责将 Docx 转为结构化 JSON。
- `docx生成器/`: 包含还原核心逻辑，负责将 JSON 转回 Docx。
- `json/`: 存放解析后的 JSON 产出物。
- `docx/`: 存放还原后的 Docx 产出物。

## 快速开始

### 1. 环境准备
确保您的电脑已安装 Python 3.8+。在 `docx处理` 目录下安装依赖：
```bash
pip install -r requirements.txt
```

### 2. 第一步：解析文档
进入 `docx解析器` 目录并运行测试脚本：
```bash
cd docx解析器
python3 test_enhanced_parser.py
```
按照提示输入本地文件路径或 URL。解析完成后，JSON 文件将保存在 `../json/` 目录下。

### 3. 第二步：还原文档
解析完成后，脚本会给出一个生成命令。通常格式如下：
```bash
cd ../docx生成器
python3 json_to_docx.py ../json/您的文件名.json ../docx/还原后的文件名.docx
```
还原后的文档将保存在 `../docx/` 目录下。

## 核心功能
- **样式继承**：自动计算 Word 中的样式继承关系，准确提取字体、字号、加粗等信息。
- **复杂表格**：完美识别并还原表格中的横向合并（colspan） and 纵向合并（rowspan）。
- **图片还原**：支持图片的提取、自动对齐（居中/左/右）以及高保真插入。
- **默认优化**：生成文档默认使用宋体，符合中文办公规范。
